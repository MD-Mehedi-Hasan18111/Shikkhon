# 🎓 শিক্ষণ (Shikkhon) - আধুনিক কোচিং একাডেমিক কেয়ার প্ল্যাটফর্ম

একটি সম্পূর্ণ, স্কেলযোগ্য ও আধুনিক **কোচিং সেন্টার ম্যানেজমেন্ট ওয়েব অ্যাপ্লিকেশন**। এটি বাংলাদেশের শীর্ষস্থানীয় অফলাইন কোচিং ইনস্টিটিউট ও একাডেমিক কেয়ার পরিচালনার বাস্তব প্রেক্ষাপট, প্রাতিষ্ঠানিক শৃঙ্খলা এবং আধুনিক ওয়েব প্রযুক্তির সমন্বয়ে তৈরি করা হয়েছে।

সিস্টেমটিতে রয়েছে পাবলিক পোর্টাল, সুপার অ্যাডমিন ম্যানেজমেন্ট কনসোল, ডেডিকেটেড শিক্ষক পোর্টাল, শিক্ষার্থী পোর্টাল, রিয়েল-টাইম মেসেঞ্জার চ্যাট সিস্টেম, মাসিক ফি ও পেমেন্ট ট্র্যাকিং এবং লাইভ নোটিফিকেশন সেন্টার।

## 🛠️ প্রযুক্তি স্ট্যাক (Technology Stack)

- **ফ্রন্টএন্ড ও ফুলস্ট্যাক ফ্রেমওয়ার্ক**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19, Server Components)
- **প্রোগ্রামিং ভাষা**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **ব্যাকএন্ড ও এপিআই**: Next.js Native Route Handlers (`src/app/api/*`)
- **ডেটাবেজ ও ওআরএম**: [MongoDB](https://www.mongodb.com/) এবং [Mongoose](https://mongoosejs.com/)
- **ক্লাউড ইমেজ হোস্টিং**: [ImgBB API](https://api.imgbb.com/) ও মাল্টি-পার্ট ফর্ম আপলোডার
- **স্টাইলিং ও থিম**: [Tailwind CSS v4](https://tailwindcss.com/)
- **ক্লায়েন্ট স্টেট ম্যানেজমেন্ট**: [Redux Toolkit](https://redux-toolkit.js.org/) ও `react-redux`
- **রিয়েল-টাইম আর্কিটেকচার**: [Socket.IO](https://socket.io/) (Persistent Server + Polling Auto-Sync)
- **ফর্ম ভ্যালিডেশন**: [React Hook Form](https://react-hook-form.com/) ও [Zod](https://zod.dev/)
- **টাইপোগ্রাফি**: গুগল ফন্ট `Hind Siliguri` (বাংলা লিপি)
- **আইকন সেট**: [Lucide React](https://lucide.dev/)

## ⚙️ সিস্টেম সেটআপ ও এনভায়রনমেন্ট কনফিগারেশন

### ১. পূর্বশর্ত (Prerequisites)
- **Node.js**: v20 বা তার পরবর্তী সংস্করণ
- **MongoDB**: লোকাল MongoDB ইনস্টলেশন অথবা MongoDB Atlas ক্লাউড ক্লাস্টার

### ২. ডিপেন্ডেন্সি ইনস্টলেশন
```bash
npm install
```

### ৩. এনভায়রনমেন্ট ফাইল কনফিগারেশন (`.env.local`)
প্রজেক্টের রুট ডিরেক্টরিতে `.env.local` ফাইল তৈরি করুন বা নিচের মতো কনফিগার করুন:

```env
# MongoDB Connection String (Atlas অথবা Local)
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.mongodb.net/shikkhon?retryWrites=true&w=majority

# Authentication & Security
JWT_SECRET=super_secret_jwt_key_at_least_32_characters_long_2026_cms
JWT_EXPIRES_IN=7d

# Application URLs
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_SOCKET_URL=http://localhost:3000

# ImgBB Cloud Image API Key
IMGBB_API_KEY=your_imgbb_api_key_here

# Super Admin Seeding Credentials (ঐচ্ছিক)
SUPER_ADMIN_PHONE=01866098078
SUPER_ADMIN_PASSWORD=AdminPass@2026
SUPER_ADMIN_NAME=প্রধান প্রশাসক (Super Admin)
```

### ৪. প্রথম সুপার অ্যাডমিন অ্যাকাউন্ট তৈরি
```bash
npm run seed:admin
```
- **মোবাইল**: `01866098078`
- **পাসওয়ার্ড**: `AdminPass@2026`

## 🔄 সামগ্রিক ব্যবহার প্রবাহ (End-to-End Usage Flows)

### ৪.১ শিক্ষার্থী ভর্তি ও ব্যাচ এনরোলমেন্ট প্রবাহ

```mermaid
graph TD
    A[অভিভাবক ও শিক্ষার্থী অফিসে আগমন] --> B[অ্যাডমিন: /admin/students এ ভর্তি তথ্য ও ছবি এন্ট্রি]
    B --> C[স্বয়ংক্রিয় স্টুডেন্ট আইডি ও লগইন একাউন্ট তৈরি]
    C --> D[অ্যাডমিন: /admin/enrollments এ ব্যাচ সিলেক্ট]
    D --> E{আসন খালি আছে?}
    E -- হ্যাঁ --> F[মাসিক ফি ও ডিসকাউন্ট নির্ধারণ করে ভর্তি সম্পন্ন]
    E -- না --> G[সতর্কবার্তা: ব্যাচের আসন পূর্ণ!]
    F --> H[শিক্ষার্থী ও শিক্ষক ড্যাশবোর্ডে ব্যাচ তালিকা দৃশ্যমান]
```

1. **ভর্তি এন্ট্রি**: অ্যাডমিন `/admin/students` পেজ থেকে শিক্ষার্থীর নাম, ফোন, অভিভাবক, স্কুল ও ছবি দিয়ে সাবমিট করবেন।
2. **লগইন তথ্য**: শিক্ষার্থীর ফোন নম্বর ও অ্যাডমিনের দেওয়া পাসওয়ার্ড দিয়ে শিক্ষার্থী সাথে সাথে যেকোনো ডিভাইস থেকে লগইন করতে পারবে।
3. **ব্যাচ এনরোলমেন্ট**: `/admin/enrollments` থেকে শিক্ষার্থীকে উপযুক্ত ব্যাচে অ্যাসাইন করা হয়। ব্যাচের সর্বোচ্চ আসন পূর্ণ থাকলে সিস্টেম স্বয়ংক্রিয়ভাবে অতিরিক্ত ভর্তি প্রতিরোধ করে।

### ৪.২ মাসিক ফি জেনারেশন ও পেমেন্ট কালেকশন প্রবাহ

```mermaid
graph TD
    A[মাসের শুরুতে অ্যাডমিন: /admin/payments এ প্রবেশ] --> B[ব্যাচ ও মাস নির্বাচন করে 'ডিউ তৈরি করুন' ক্লিক]
    B --> C[এনরোলমেন্টের মাসিক ফি ও ডিসকাউন্ট অনুযায়ী স্বয়ংক্রিয় ডিউ জেনারেট]
    C --> D[শিক্ষার্থী পোর্টালে বকেয়া ফি স্ট্যাটাস দৃশ্যমান]
    D --> E[অভিভাবক ক্যাশ/বিকাশ/নগদে ফি পরিশোধ]
    E --> F[অ্যাডমিন: 'পেমেন্ট গ্রহণ' বাটনে ক্লিক করে ট্রানজেকশন তথ্য এন্ট্রি]
    F --> G[পেমেন্ট স্ট্যাটাস 'Paid' এ রূপান্তর ও ডিজিটাল রিসিপ্ট তৈরি]
```

1. **মাসিক ডিউ তৈরি**: প্রতি মাসের শুরুতে অ্যাডমিন ব্যাচ সিলেক্ট করে **"মাসিক ডিউ জেনারেট"** চাপলে প্রত্যেক শিক্ষার্থীর ডিসকাউন্ট হিসাব করে বকেয়া তৈরি হয়ে যায়।
2. **ফি কালেকশন**: শিক্ষার্থী ফি দিলে অ্যাডমিন নগদ, বিকাশ, রকেট বা ব্যাংকের ট্রানজেকশন আইডি দিয়ে পেমেন্ট সংরক্ষণ করবেন।
3. **রিসিপ্ট প্রিন্ট**: পেমেন্ট এন্ট্রি হলেই প্রিন্টযোগ্য রসিদ নম্বর তৈরি হয় যা শিক্ষার্থীও তার পোর্টালে দেখতে পায়।

### ৪.৩ রিয়েল-টাইম চ্যাট ও পার-ইউজার হিস্ট্রি প্রবাহ

```mermaid
sequenceDiagram
    autonumber
    actor A as ব্যবহারকারী A (প্রেরক)
    participant S as সার্ভার ও ডেটাবেস
    actor B as ব্যবহারকারী B (প্রাপক)

    S->>B: লাইভ ডেলিভারি ও আনরিড কাউন্ট বৃদ্ধি

    B->>S: চ্যাট ওপেন করলেন (mark_read)

- **মোবাইল মেসেঞ্জার ইউজার এক্সপেরিয়েন্স**: মোবাইল স্ক্রিনে যখন ব্যবহারকারী কোনো চ্যাটে ক্লিক করেন, তখন বামের তালিকা লুকিয়ে শুধুমাত্র মেসেজিং স্ক্রিন ও ব্যাক বাটন প্রদর্শিত হয়।
- **একতরফা ডিলিট সুবিধা**: ব্যবহারকারী A চ্যাট ডিলিট করলে ব্যবহারকারী B-এর চ্যাট হিস্ট্রি সুরক্ষিত থাকে। A পরবর্তীতে নতুন করে চ্যাট শুরু করতে পারেন।

### ৪.৪ নোটিফিকেশন বেল ও রিড-ট্র্যাকিং প্রবাহ

- **কাদের জন্য প্রযোজ্য**: শিক্ষক ও শিক্ষার্থী পোর্টালের শীর্ষ ন্যাভবারে নোটিফিকেশন বেল প্রদর্শিত হয়।
- **স্বয়ংক্রিয় নোটিফিকেশন তৈরি**: যখনই কোনো নতুন **নোটিশ (Notice)**, **ব্লগ পোস্ট (Blog)** বা **ইভেন্ট (Event)** প্রকাশিত হয়, শিক্ষক ও শিক্ষার্থীদের জন্য স্বয়ংক্রিয় নোটিফিকেশন জেনারেট হয়।
- **লাইভ কাউন্টার ও অ্যাকশন**: বেল আইকনে অপঠিত নোটিফিকেশনের লাল ব্যাজ ভেসে ওঠে। ক্লিকে ড্রপডাউনে নোটিফিকেশনের শিরোনাম দেখা যায় এবং তাতে ক্লিক করলে নোটিফিকেশনটি স্বয়ংক্রিয়ভাবে পঠিত (Read) হিসেবে চিহ্নিত হয়ে সরাসরি সংশ্লিষ্ট নোটিশ, ব্লগ বা ইভেন্ট পেজে রিডাইরেক্ট করে।

## 🏛️ সুপার অ্যাডমিন ব্যবহারের পূর্ণাঙ্গ গাইডলাইন (Super Admin Guide)

সুপার অ্যাডমিন হলেন প্রতিষ্ঠানের প্রধান নিয়ন্ত্রক। অ্যাডমিন প্যানেল রুট: `/admin`

### ১. ড্যাশবোর্ড ওভারভিউ (`/admin`)
- মোট শিক্ষার্থী, মোট শিক্ষক, রানিং সেশন ও সক্রিয় ব্যাচের লাইভ কাউন্ট।
- আজকের ক্লাসের সময়সূচী এবং আজকের উপস্থিতির শতকরা হার।
- সাম্প্রতিক প্রকাশিত নোটিশ, আসন্ন ইভেন্ট ও প্ল্যাটফর্মের সাম্প্রতিক অ্যাক্টিভিটি।

### ২. শিক্ষার্থী ব্যবস্থাপনা (`/admin/students`)
- **নতুন ভর্তি**: **"+ নতুন শিক্ষার্থী ভর্তি"** বাটনে ক্লিক করে শিক্ষার্থীর ছবি, নাম, মোবাইল নম্বর, লগইন পাসওয়ার্ড, শ্রেণি এবং অভিভাবকের জরুরি ফোন নম্বর দিয়ে ভর্তি সম্পন্ন করুন।
- **অনুসন্ধান**: রোল, নাম, ফোন বা ক্লাস দিয়ে ফিল্টার করুন।
- **প্রোফাইল ভিউ**: শিক্ষার্থীর ছবি ও গার্ডিয়ানের বিস্তারিত কার্ড আকারে দেখতে চোখের আইকনে ক্লিক করুন।
- **তথ্য সম্পাদনা ও স্ট্যাটাস**: শিক্ষার্থীর তথ্য আপডেট অথবা প্রয়োজনবোধে স্ট্যাটাস Active/Inactive করুন।

### ৩. শিক্ষক ব্যবস্থাপনা (`/admin/teachers`)
- **নতুন শিক্ষক নিয়োগ**: **"+ নতুন শিক্ষক যোগ করুন"** বাটনে ক্লিক করে শিক্ষকের পাসপোর্ট ছবি, নাম, মোবাইল নম্বর, লগইন পাসওয়ার্ড, পদবি ও পাঠদানের বিষয়সমূহ দিয়ে অ্যাকাউন্ট তৈরি করুন।
- **স্ট্যাটাস পরিবর্তন**: কোনো শিক্ষক ছুটি নিলে বা দায়িত্ব হস্তান্তর করলে তাকে নিষ্ক্রিয় (Inactive) করা যায়।

### ৪. অ্যাকাডেমিক সেশন (`/admin/sessions`)
- নতুন শিক্ষাবর্ষ তৈরি করুন (যেমন: "২০২৬ শিক্ষাবর্ষ")।
- বর্তমান রানিং সেশনটি নির্বাচন করে `isCurrent: true` মার্ক করুন।

### ৫. ব্যাচ ও ক্লাসরুটিন (`/admin/batches`)
- শ্রেণি ও বিষয় নির্ধারণ করে ব্যাচ খুলুন (যেমন: `Class 10 - Physics Special`)।
- ক্লাসরুমের সর্বোচ্চ সিট ক্যাপাসিটি (যেমন: ৪০ জন) নির্ধারণ করুন।
- নির্ধারিত শিক্ষক অ্যাসাইন করুন এবং সপ্তাহের বার ও সময়সূচী (Timetable) যুক্ত করুন।

### ৬. ব্যাচ ভর্তি ও স্থানান্তর (`/admin/enrollments`)
- নির্দিষ্ট ব্যাচে শিক্ষার্থী নির্বাচন করে ভর্তি করুন।
- মাসিক ফি এবং বিশেষ আর্থিক ছাড় (Waiver Percentage) সেট করুন।
- **ব্যাচ ট্রান্সফার**: এক ব্যাচ থেকে অন্য ব্যাচে স্থানান্তর করলে পূর্বের উপস্থিতি ও হিসেব অক্ষুণ্ণ রেখে নতুন ব্যাচে শিফট হয়ে যায়।

### ৭. ডিজিটাল ক্লাসরুম হাজিরা (`/admin/attendance`)
- ব্যাচ ও তারিখ সিলেক্ট করলেই শিক্ষার্থীদের রোল অনুযায়ী তালিকা আসবে।
- এক ক্লিকে সবাইকে উপস্থিত বা অনুপস্থিত মার্ক করুন, প্রয়োজনে লেট (Late) দিন এবং **"সংরক্ষণ করুন"** চাপুন।

### ৮. পরীক্ষা ও ফলাফল তৈরি (`/admin/exams`)
- ব্যাচ সিলেক্ট করে পরীক্ষার নাম (যেমন: "অধ্যায়-১ মূল্যায়ন পরীক্ষা"), তারিখ, পূর্ণমান ও পাস মার্ক দিন।
- শিক্ষার্থীদের প্রাপ্ত নম্বর ইনপুট দিন; সিস্টেম স্বয়ংক্রিয়ভাবে লেটার গ্রেড (A+, A, ইত্যাদি) হিসাব করবে।
- **ফলাফল প্রকাশ**: ড্রাফট হিসেবে সংরক্ষণ করে পরবর্তীতে এক ক্লিকে "প্রকাশিত" করুন যাতে শিক্ষার্থীরা দেখতে পারে।

### ৯. মাসিক ফি ও পেমেন্ট ট্র্যাকিং (`/admin/payments`)
- **ডিউ তৈরি**: মাসের শুরুতে **"মাসিক ডিউ তৈরি করুন"** বাটনে ক্লিক করে ব্যাচ ও মাস বেছে নিন।
- **পেমেন্ট গ্রহণ**: বকেয়া থাকা শিক্ষার্থীর নামের পাশে **"পেমেন্ট নিন"** বাটনে ক্লিক করে পরিশোধিত টাকা, পেমেন্ট মাধ্যম (ক্যাশ, বিকাশ, নগদ) ও ট্রানজেকশন আইডি দিয়ে সেভ করুন।
- **রিসিপ্ট প্রিন্ট**: তাৎক্ষণিক ডিজিটাল পেমেন্ট ভাউচার প্রিন্ট করার সুবিধা।

### ১০. নোটিশ বোর্ড (`/admin/notices`)
- জরুরি বিজ্ঞপ্তি তৈরি করুন; বিজ্ঞপ্তির স্ক্যান কপি বা ছবি যুক্ত করুন।
- হোমপেজে গুরুত্বপূর্ণ নোটিশ সবার উপরে রাখতে **"পিন করুন"** টিক দিন।
- নোটিশের টার্গেট অডিয়েন্স (সকলের জন্য, কেবল শিক্ষক, নাকি কেবল শিক্ষার্থী) নির্বাচন করুন।

### ১১. ব্লগ ও আর্টিকেল (`/admin/blog`)
- শিক্ষার্থীদের পড়াশোনার টিপস ও গাইডলাইন ব্লগ লিখুন ও কভার ছবি যুক্ত করুন।

### ১২. ইভেন্ট ও প্রতিযোগিতা (`/admin/events`)
- সেমিনার, পুরস্কার বিতরণী বা ছুটির ইভেন্ট তারিখ, সময়, ভেন্যু ও ফটো গ্যালারিসহ পাবলিশ করুন।

### ১৩. সাইট সেটিংস (`/admin/settings`)
- প্রতিষ্ঠানের নাম, স্লোগান, ঠিকানা, হটলাইন ফোন ও অফিসিয়াল হোয়াটসঅ্যাপ নম্বর পরিবর্তন করুন।
- হোমপেজের ফুল-উইডথ ব্যানার ছবি ImgBB আপলোডারের মাধ্যমে এক ক্লিকে আপডেট করুন।

### ১৪. অভ্যন্তরীণ চ্যাট সিস্টেম (`/admin/messages`)
- শিক্ষক বা শিক্ষার্থীদের সাথে রিয়েল-টাইম চ্যাট করুন।
- কোনো কথোপকথন ডিলিট করতে চাইলে থ্রি-ডট থেকে **"কথোপকথন মুছুন"** চাপুন।

```

### শিক্ষকদের প্রতিটি অ্যাকশন নির্দেশিকা:
1. **আজকের ক্লাসের রুটিন দেখা**: ড্যাশবোর্ডে প্রবেশের সাথে সাথে শিক্ষক দেখতে পাবেন আজ কোন কোন ব্যাচে কোন সময়ে এবং কোন কক্ষে তার ক্লাস রয়েছে।
2. **ক্লাসরুমে হাজিরা গ্রহণ (`/dashboard/teacher/attendance`)**:
   - ক্লাসরুমে গিয়ে মোবাইল বা ল্যাপটপে ব্যাচ ও তারিখ সিলেক্ট করুন।
   - শিক্ষার্থীদের নামের পাশে সবুজ (উপস্থিত), লাল (অনুপস্থিত) বা হলুদ (বিলম্বিত) বাটনে ট্যাপ করে নিমেষেই হাজিরা সাবমিট করুন।
3. **পরীক্ষার নম্বর এন্ট্রি (`/dashboard/teacher/exams`)**:
   - শিক্ষক তার নির্ধারিত ব্যাচের পরীক্ষার খাতা দেখে প্রাপ্ত নম্বর সিস্টেমে ইনপুট দিতে পারেন।
4. **চ্যাট ও যোগাযোগ (`/dashboard/teacher/messages`)**:
   - সুপার অ্যাডমিন বা শিক্ষার্থীদের মেসেজের উত্তর দিন।
   - মোবাইল স্ক্রিনে চ্যাট ওপেন করলে পুরো চ্যাট বক্স ভিউ হবে, কাজ শেষে ব্যাক বাটন দিয়ে চ্যাট লিস্টে ফিরুন।
5. **নোটিফিকেশন সেন্টার**:
   - শীর্ষ ন্যাভবারের বেল আইকনে লাল কাউন্ট দেখে নতুন নোটিশ ও ইভেন্ট সম্পর্কে তাৎক্ষণিক অবগত হন।
6. **প্রোফাইল মেন্যু ও ড্রপডাউন**:
   - উপরের ডান কোণে শিক্ষকের নাম, ফোন নম্বর ও "Teacher" পদবি প্রদর্শিত হয়। এখান থেকে শিক্ষক নিজের ছবি ও বায়ো আপডেট করতে পারেন।

## 👨‍🎓 শিক্ষার্থী পোর্টাল ব্যবহারের পূর্ণাঙ্গ গাইডলাইন (Student Guide)

শিক্ষার্থী পোর্টাল রুট: `/dashboard/student`  
লগইন তথ্য: অফিসে ভর্তির সময় প্রদত্ত মোবাইল নম্বর ও পাসওয়ার্ড।

```
[ শিক্ষার্থী পোর্টাল নেভিগেশন ]
├── 🏠 ওভারভিউ ও প্রোফাইল কার্ড (/dashboard/student)
├── 📚 আমার ব্যাচসমূহ ও ক্লাসরুটিন (/dashboard/student/batches)
├── 📈 উপস্থিতির বিবরণী (/dashboard/student/attendance)
├── 🏆 পরীক্ষার ফলাফল ও মেধা স্থান (/dashboard/student/results)
├── 💬 শিক্ষক ও অ্যাডমিনের সাথে চ্যাট (/dashboard/student/messages)
├── 📢 প্রাতিষ্ঠানিক নোটিশ বোর্ড (/dashboard/student/notices)
├── 👤 প্রোফাইল ও অভিভাবক তথ্য (/dashboard/student/profile)
└── 🔒 নিরাপত্তা ও পাসওয়ার্ড পরিবর্তন (/dashboard/student/security)
```

### শিক্ষার্থীদের প্রতিটি অ্যাকশন নির্দেশিকা:
1. **ক্লাস রুটিন ও ব্যাচ তথ্য**: শিক্ষার্থী কোন কোন ব্যাচে এনরোল করা আছে, কোন শিক্ষক ক্লাস নিচ্ছেন এবং সাপ্তাহিক ক্লাসের সময়সূচী দেখতে পারে।
2. **উপস্থিতির শতাংশ ও গ্রাফ**: চলতি মাসে কতদিন উপস্থিত বা অনুপস্থিত ছিল তা রঙিন প্রগ্রেস বারে দেখতে পাবে।
3. **অনলাইন রেজাল্ট কার্ড**: পরীক্ষা প্রকাশিত হওয়ার সাথে সাথে শিক্ষার্থী নিজের প্রাপ্ত নম্বর, গ্রেড এবং ব্যাচে নিজের মেধা স্থান (Rank) দেখতে পারবে।
4. **চ্যাট মেসেঞ্জার সুবিধা**:
   - শিক্ষক বা কোচিং অ্যাডমিনের সাথে পড়াশোনা সংক্রান্ত বিষয়ে সরাসরি চ্যাট করতে পারবে।
   - মেসেজ পৌঁছালে সিঙ্গেল টিক (`✓ অপঠিত`) এবং শিক্ষক দেখলে ডাবল টিক (`✓✓ দেখা হয়েছে`) দৃশ্যমান হবে।
   - *নীতিমালা*: শিক্ষার্থীদের পরস্পরের মধ্যে চ্যাট করার অনুমতি নেই (কেবল শিক্ষক ও অ্যাডমিনের সাথেই চ্যাট করা যাবে)।
5. **নোটিফিকেশন বেল অ্যালার্ট**:
   - নতুন কোনো নোটিশ, ব্লগ বা ইভেন্ট এলে বেলের লাল ব্যাজে কাউন্ট শো করবে। নোটিফিকেশনে ট্যাপ করলেই সরাসরি বিস্তারিত নোটিশটি পড়া যাবে।
6. **পাসওয়ার্ড পরিবর্তন (`/dashboard/student/security`)**:
   - শিক্ষার্থী তার অ্যাকাউন্টের নিরাপত্তা নিশ্চিত করতে যেকোনো সময় নিজের পাসওয়ার্ড পরিবর্তন করতে পারবে।

## ⚡ রিয়েল-টাইম চ্যাট ও সকেট সার্ভার (Real-Time Communication)

সিস্টেমে ব্যবহৃত হয়েছে **Socket.IO** যা কোনো পেজ রিলোড ছাড়াই তাৎক্ষণিক মেসেজ ডেলিভারি নিশ্চিত করে।

### সার্ভার চালনা করার কমান্ড
```bash
# টার্মিনাল ১: Next.js ফ্রন্টএন্ড ও REST API (Port 3000)
npm run dev

# টার্মিনাল ২: পারসিস্টেন্ট সকেট সার্ভার (Port 3000/3001)
npm run socket
```

> [!NOTE]
> কোনো কারণে সকেট সার্ভার ডিসকানেক্ট থাকলেও ফ্রন্টএন্ডে স্বয়ংক্রিয় REST Polling ফলব্যাক (প্রতি ২ সেকেন্ড পর পর লাইভ সিঙ্ক) চালু থাকে, যাতে মেসেজ আদান-প্রদান কখনো বাধাগ্রস্ত না হয়।
