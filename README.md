# 🎓 কোচিং ম্যানেজমেন্ট সিস্টেম (Coaching Management System)

একটি পূর্ণাঙ্গ, আধুনিক ও স্কেলযোগ্য **কোচিং সেন্টার ম্যানেজমেন্ট ওয়েব প্ল্যাটফর্ম**। এটি আধুনিক ওয়েব প্রযুক্তি এবং বাংলাদেশের বাস্তব শিক্ষাপ্রতিষ্ঠান ও কোচিং ইনস্টিটিউট পরিচালনার সামগ্রিক চাহিদাকে কেন্দ্র করে তৈরি করা হয়েছে।

সিস্টেমটিতে রয়েছে পাবলিক ওয়েবসাইট, অ্যাডমিন ম্যানেজমেন্ট কনসোল, শিক্ষক পোর্টাল, শিক্ষার্থী পোর্টাল এবং সকেট-ভিত্তিক রিয়েল-টাইম চ্যাট সিস্টেম।

## 🛠️ প্রযুক্তি স্ট্যাক (Technology Stack)

- **কোর ফ্রেমওয়ার্ক**: [Next.js 16](https://nextjs.org/) (App Router, Turbopack, React 19, Server Components)
- **প্রোগ্রামিং ভাষা**: [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **ব্যাকএন্ড ও এপিআই**: Next.js Native Route Handlers (`src/app/api/*`)
- **ডেটাবেজ ও ORM**: [MongoDB](https://www.mongodb.com/) এবং [Mongoose](https://mongoosejs.com/)
- **স্টাইলিং ও থিম**: [Tailwind CSS v4](https://tailwindcss.com/)
- **ক্লায়েন্ট স্টেট ম্যানেজমেন্ট**: [Redux Toolkit](https://redux-toolkit.js.org/) ও `react-redux`
- **রিয়েল-টাইম আর্কিটেকচার**: [Socket.IO](https://socket.io/) (Persistent Server + Client)
- **ফর্ম ভ্যালিডেশন**: [React Hook Form](https://react-hook-form.com/) ও [Zod](https://zod.dev/)
- **টাইপোগ্রাফি**: গুগল ফন্ট `Hind Siliguri` (বাংলা লিপি)
- **আইকন সেট**: [Lucide React](https://lucide.dev/)

## ⚙️ সিস্টেম সেটআপ ও এনভায়রনমেন্ট কনফিগারেশন

### ১. পূর্বশর্ত (Prerequisites)

- **Node.js**: v20 বা তার পরবর্তী সংস্করণ
- **MongoDB**: লোকাল MongoDB ইনস্টলেশন অথবা MongoDB Atlas ক্লাউড ক্লাস্টার

### ২. ডিপেন্ডেন্সি ইনস্টলেশন

```bash
npm install
```

### ৩. এনভায়রনমেন্ট ফাইল কনফিগারেশন (`.env.local`)

প্রজেক্টের রুট ডিরেক্টরিতে `.env.local` ফাইল তৈরি করুন অথবা যাচাই করুন:

```env
# MongoDB Connection String (Atlas অথবা Local)
MONGODB_URI=mongodb+srv://<username>:<password>@cluster0.yai2s.mongodb.net/shikkhon?retryWrites=true&w=majority&appName=Cluster0

# Authentication & Security
JWT_SECRET=super_secret_jwt_key_at_least_32_characters_long_2026_cms
JWT_EXPIRES_IN=7d

# Application URLs
NEXT_PUBLIC_APP_URL=http://localhost:3000
NEXT_PUBLIC_SOCKET_URL=http://localhost:4000

# Super Admin Seeding Credentials (ঐচ্ছিক)
SUPER_ADMIN_PHONE=01866098078
SUPER_ADMIN_PASSWORD=AdminPass@2026
SUPER_ADMIN_NAME=প্রধান প্রশাসক (Super Admin)
```

> [!NOTE]
> MongoDB Atlas সংযোগ স্ট্রিং-এ ডেটাবেজ নামের পর সরাসরি `?retryWrites=true&w=majority` থাকতে হবে।

## 🔑 অ্যাকাউন্ট তৈরি ও সাইন-আপ ফ্লো (Signup & Provisioning Flow)

কোচিং ম্যানেজমেন্ট সিস্টেমের নিরাপত্তা ও প্রাতিষ্ঠানিক অখণ্ডতা বজায় রাখার জন্য **পাবলিক সেলফ-রেজিস্ট্রেশন বা সরাসরি উন্মুক্ত সাইন-আপ ফর্ম রাখা হয়নি**। এতে বহিরাগত কেউ নিজে নিজে অ্যাডমিন, শিক্ষক বা শিক্ষার্থীর ভুয়া অ্যাকাউন্ট তৈরি করতে পারে না।

```
                                [ সিস্টেম অ্যাকাউন্ট তৈরির ফ্লো ]
                                                │
         ┌──────────────────────────────────────┼──────────────────────────────────────┐
         ▼                                      ▼                                      ▼
1. সুপার অ্যাডমিন (Super Admin)         2. শিক্ষক অ্যাকাউন্ট                   3. শিক্ষার্থী অ্যাকাউন্ট
  (CLI কমান্ডের মাধ্যমে সুরক্ষিত)       (অ্যাডমিন কর্তৃক ড্যাশবোর্ড থেকে)      (অ্যাডমিন কর্তৃক ড্যাশবোর্ড থেকে)
         │                                      │                                      │
  npm run seed:admin                     /admin/teachers                        /admin/students
         │                                      │                                      │
  মোবাইল: 01866098078                   অটো টিচার কোড (TCH-XXX)                 অটো স্টুডেন্ট আইডি (STU-XXXX)
  পাসওয়ার্ড: AdminPass@2026               ফোন নম্বর ও প্রাথমিক পাসওয়ার্ড         অভিভাবকের তথ্য ও লগইন পাসওয়ার্ড
```

### ১. সুপার অ্যাডমিন অ্যাকাউন্ট তৈরি (Super Admin CLI)

সিস্টেমের প্রথম অ্যাডমিন অ্যাকাউন্ট টার্মিনাল কমান্ডের মাধ্যমে সরাসরি ডেটাবেজে সুরক্ষিতভাবে তৈরি করা হয়:

```bash
npm run seed:admin
```

- **ডিফল্ট মোবাইল**: `01866098078`
- **ডিফল্ট পাসওয়ার্ড**: `AdminPass@2026`
- কাস্টম ক্রেডেনশিয়াল দিতে চাইলে `.env.local`-এ `SUPER_ADMIN_PHONE` ও `SUPER_ADMIN_PASSWORD` পরিবর্তন করে স্ক্রিপ্টটি পুনরায় রান করুন।

### ২. শিক্ষক অ্যাকাউন্ট তৈরি (Teacher Creation)

1. সুপার অ্যাডমিন বা অ্যাডমিন হিসেবে লগইন করে `/admin/teachers` পেজে যান।
2. **"নতুন শিক্ষক যোগ করুন"** বাটনে ক্লিক করুন।
3. শিক্ষকের পুরো নাম, ১১ ডিজিটের বাংলাদেশী ফোন নম্বর (`01XXXXXXXXX`), ইমেইল, পাঠদানের বিষয়সমূহ, শিক্ষাগত যোগ্যতা এবং প্রাথমিক লগইন পাসওয়ার্ড দিয়ে সাবমিট করুন।
4. সিস্টেমে স্বয়ংক্রিয়ভাবে একটি ইউনিক টিচার কোড (যেমন: `TCH-101`) ও `teacher` রোলের ইউজার তৈরি হবে।

### ৩. শিক্ষার্থী অ্যাকাউন্ট ও ভর্তি ফ্লো (Student Creation & Admission)

1. অ্যাডমিন ড্যাশবোর্ড থেকে `/admin/students` পেজে যান।
2. **"নতুন শিক্ষার্থী ভর্তি"** বাটনে ক্লিক করুন।
3. শিক্ষার্থীর নাম, মোবাইল নম্বর, শিক্ষাপ্রতিষ্ঠানের নাম, শ্রেণি (যেমন: Class 9, Class 10, HSC), বিভাগ, অভিভাবকের নাম, মোবাইল নম্বর এবং লগইন পাসওয়ার্ড এন্ট্রি করুন।
4. সাবমিট করার সাথে সাথে সিস্টেমে ইউনিক স্টুডেন্ট আইডি (যেমন: `STU-2026-0001`) এবং `student` রোলের লগইন ইউজার সক্রিয় হবে।
5. এরপর `/admin/enrollments` মেন্যুতে গিয়ে শিক্ষার্থীকে নির্ধারিত রানিং সেশন ও ব্যাচে যুক্ত (Enroll) করা হয়।

### ৪. পাবলিক ভর্তির আবেদন (Admission Inquiry Flow)

- সাধারণ শিক্ষার্থী বা অভিভাবক ওয়েবসাইট থেকে সরাসরি `/admissions` পেজে অথবা হোমপেজের ফর্ম থেকে ভর্তির আগ্রহ জানিয়ে আবেদন পাঠাতে পারেন।
- অ্যাডমিন সেই তথ্য দেখে শিক্ষার্থীর সাথে যোগাযোগ করে সরাসরি সিস্টেমে শিক্ষার্থী হিসেবে তালিকাভুক্ত করেন।

## 🔐 লগইন ও ড্যাশবোর্ড ডিসপ্যাচ ফ্লো (Signin & Dispatch Flow)

সকল ইউজার (অ্যাডমিন, শিক্ষক, শিক্ষার্থী ও অভিভাবক) একটিমাত্র প্রমিত লগইন পেজ থেকে সিস্টেমে প্রবেশ করেন।

### ১. লগইন ধাপসমূহ (Step-by-Step Signin)

1. ব্রাউজারে যান: `http://localhost:3000/login`
2. **মোবাইল নম্বর**: আপনার নিবন্ধিত ১১ ডিজিটের নম্বর দিন (যেমন: `01866098078`)।
3. **পাসওয়ার্ড**: আপনার গোপন পাসওয়ার্ড দিন (পাসওয়ার্ড দেখতে চোখ আইকনে ক্লিক করতে পারেন)।
4. **"প্রবেশ করুন"** বাটনে ক্লিক করুন।

### ২. স্বয়ংক্রিয় ভূমিকাভিত্তিক ডিরেকশন (Role-Based Dispatch)

সফল লগইনের পর সার্ভার একটি সুরক্ষিত `HttpOnly` JWT কুকি সেট করে এবং ক্লায়েন্টকে `/dashboard` পাথে রিডাইরেক্ট করে। `/dashboard` রুট ইউজারের ভূমিকা (Role) পরীক্ষা করে তাৎক্ষণিকভাবে নির্দিষ্ট পোর্টালে পাঠিয়ে দেয়:

| ইউজারের ভূমিকা (Role)                 | রিডাইরেক্ট রুট (Portal Destination) | অনুমোদিত অ্যাক্সেস                                           |
| :------------------------------------ | :---------------------------------- | :----------------------------------------------------------- |
| **`super_admin` / `admin` / `staff`** | `/admin`                            | সম্পূর্ণ প্রাতিষ্ঠানিক ম্যানেজমেন্ট ও কন্ট্রোল প্যানেল       |
| **`teacher`**                         | `/dashboard/teacher`                | শিক্ষকের নিজস্ব ক্লাস শিডিউল, হাজিরা ও নম্বর ইনপুট পোর্টাল   |
| **`student` / `guardian`**            | `/dashboard/student`                | শিক্ষার্থীর নিজস্ব রুটিন, ফলাফল, হাজিরা ও হেল্পডেস্ক পোর্টাল |

> [!TIP]
> অননুমোদিত কেউ অন্য রোলের ইউআরএল-এ সরাসরি ঢুকতে চেষ্টা করলে নেক্সট.জেএস মিডলওয়্যার ও সার্ভার গার্ড স্বয়ংক্রিয়ভাবে অ্যাক্সেস ব্লক করে এবং লগইন পেজে ফিরিয়ে দেয়।

## 🏛️ অ্যাডমিন পোর্টাল ব্যবহারের বিস্তারিত নির্দেশিকা (Admin Portal)

অ্যাডমিন প্যানেলটি সম্পূর্ণ বাংলায় তৈরি এবং প্রতিষ্ঠানের যাবতীয় কার্যক্রম পরিচালনার জন্য ১৩টি প্রধান মডিউল নিয়ে গঠিত:

### ১. মূল ড্যাশবোর্ড (`/admin`)

- মোট সক্রিয় শিক্ষার্থী, কর্মরত শিক্ষক, রানিং সেশন ও সক্রিয় ব্যাচের লাইভ পরিসংখ্যান।
- আজকের ক্লাসের সময়সূচী এবং দৈনিক উপস্থিতির হার।
- সাম্প্রতিক নোটিশ, আসন্ন ইভেন্ট ও প্ল্যাটফর্ম অ্যাক্টিভিটি হিস্টোরি।

### ২. শিক্ষার্থী ব্যবস্থাপনা (`/admin/students`)

- **অনুসন্ধান ও ফিল্টারিং**: নাম, রোল, ফোন বা শ্রেণি দিয়ে তাৎক্ষণিক শিক্ষার্থী অনুসন্ধান।
- **নতুন নিবন্ধন**: সম্পূর্ণ তথ্য দিয়ে নতুন শিক্ষার্থী সংযোজন।
- **প্রোফাইল ভিউ**: শিক্ষার্থীর ছবি, অভিভাবকের তথ্য, রক্ত গ্রুপ ও ঠিকানার বিস্তারিত প্রোফাইল কার্ড।
- **সম্পাদনা ও সফট-ডিঅ্যাক্টিভেশন**: অ্যাকাডেমিক ইতিহাস অক্ষুণ্ণ রেখে শিক্ষার্থী নিষ্ক্রিয়করণ।

### ৩. শিক্ষক ব্যবস্থাপনা (`/admin/teachers`)

- শিক্ষকদের তালিকা, তাদের পদবি, পাঠদানের বিষয় এবং নির্ধারিত ব্যাচ সংখ্যা।
- নতুন শিক্ষক যুক্ত করা, বায়ো ও শিক্ষাগত যোগ্যতা আপডেট।
- শিক্ষকদের স্ট্যাটাস নিয়ন্ত্রণ (Active / Inactive)।

### ৪. শিক্ষাবর্ষ বা সেশন (`/admin/sessions`)

- নতুন অ্যাকাডেমিক সেশন তৈরি (যেমন: "২০২৬ শিক্ষাবর্ষ")।
- কোন সেশনটি বর্তমানে রানিং তা সেট করা (`isCurrent: true`)।
- পুরোনো সেশন আর্কাইভ করা।

### ৫. ব্যাচ ও ক্লাসরুটিন (`/admin/batches`)

- শ্রেণি ও বিষয় নির্ধারণ করে নতুন ব্যাচ খোলা।
- বিষয়ভিত্তিক শিক্ষক অ্যাসাইন করা।
- সপ্তাহের কোন কোন দিন কয়টায় ক্লাস হবে তা নির্ধারণ (টাইমটেবিল)।
- ব্যাচের সর্বোচ্চ আসন সংখ্যা (Seat Capacity) নির্ধারণ।

### ৬. ব্যাচ ভর্তি ও স্থানান্তর (`/admin/enrollments`)

- নির্দিষ্ট ব্যাচে শিক্ষার্থী ভর্তি করা (সিট খালি থাকা সাপেক্ষে অটো ভ্যালিডেশন)।
- মাসিক ফি এবং বিশেষ আর্থিক ছাড় (Discount/Waiver) নির্ধারণ।
- **ব্যাচ ট্রান্সফার**: এক ব্যাচ থেকে অন্য ব্যাচে ট্রান্সফার করলে পূর্বের ইতিহাস অক্ষুণ্ণ থেকে স্বয়ংক্রিয়ভাবে নতুন ব্যাচে শিফট হয়।

### ৭. ডিজিটাল হাজিরা (`/admin/attendance`)

- সেশন, ব্যাচ ও তারিখ সিলেক্ট করে এক ক্লিকে সম্পূর্ণ ব্যাচের উপস্থিতি নেওয়া।
- উপস্থিতি, অনুপস্থিতি ও লেট (Late) চিহ্নিতকরণ।
- একক বা বাল্ক সংশোধন সুবিধা এবং শতকরা উপস্থিতির হার পর্যবেক্ষণ।

### ৮. পরীক্ষা ও ফলাফল (`/admin/exams`)

- ব্যাচভিত্তিক পরীক্ষা তৈরি (তারিখ, পূর্ণমান, পাস মার্ক)।
- শিক্ষার্থীদের প্রাপ্ত নম্বর ইনপুট ও গ্রেড (A+, A, B...) অটো জেনারেশন।
- ফলাফল প্রকাশ নিয়ন্ত্রণ (ড্রাফট রাখা এবং এক ক্লিকে পাবলিশ করা)।

### ৯. নোটিশ বোর্ড (`/admin/notices`)

- প্রাতিষ্ঠানিক জরুরি ও সাধারণ বিজ্ঞপ্তি প্রকাশ।
- টার্গেট অডিয়েন্স নির্বাচন (সকলের জন্য, শুধু শিক্ষক, নাকি শুধু শিক্ষার্থী)।
- জরুরি নোটিশ হোমপেজে পিন করে রাখার সুবিধা।

### ১০. ব্লগ ও আর্টিকেল (`/admin/blog`)

- শিক্ষামূলক টিপস, স্টাডি গাইড ও পরামর্শমূলক ব্লগ পোস্ট রচনা ও প্রকাশ।
- ভিউ কাউন্টার ও পাঠকদের জন্য ফিচার্ড ব্লগ নির্বাচন।

### ১১. ইভেন্ট ও অনুষ্ঠান (`/admin/events`)

- সেমিনার, পুরস্কার বিতরণী, অভিভাবক সমাবেশ বা ছুটির ইভেন্ট শিডিউল করা।
- তারিখ, সময় ও স্থান যুক্ত করে প্রকাশ করা।

### ১২. রিয়েল-টাইম মেসেজিং (`/admin/messages`)

- শিক্ষক ও শিক্ষার্থীদের সাথে ওয়ান-টু-ওয়ান সরাসরি চ্যাট।
- তাৎক্ষণিক উত্তর দেওয়া, মেসেজ ডেলিভারি ও আনরিড মেসেজ নোটিফিকেশন।
- আপত্তিকর বার্তার ক্ষেত্রে রিপোর্ট ম্যানেজমেন্ট।

### ১৩. সাইট সেটিংস (`/admin/settings`)

- প্রতিষ্ঠানের নাম, স্লোগান ও লোগো পরিবর্তন।
- হটলাইন ফোন নম্বর ও অফিসিয়াল হোয়াটসঅ্যাপ নম্বর (`+880 1866-098078`) আপডেট।
- শিক্ষার্থী-শিক্ষক সরাসরি চ্যাট চালু বা বন্ধের পলিসি নির্ধারণ।

## 👨‍🏫 শিক্ষক পোর্টাল ব্যবহারের নির্দেশিকা (Teacher Portal)

শিক্ষকদের জন্য ডেডিকেটেড পোর্টাল রুট: `/dashboard/teacher`

```
[ শিক্ষক পোর্টালের মূল মেন্যুসমূহ ]
├── 📊 ওভারভিউ ও আজকের ক্লাসের সময়সূচী
├── 👥 আমার নির্ধারিত ব্যাচসমূহ ও স্টুডেন্ট লিস্ট
├── 📝 ডিজিটাল ক্লাসরুম হাজিরা ইনপুট
├── 📋 পরীক্ষার নম্বর এন্ট্রি ও রেজাল্ট শিট
├── 📢 জরুরি নোটিশ ও প্রাতিষ্ঠানিক ইভেন্ট
└── 💬 অ্যাডমিন ও শিক্ষার্থীদের সাথে চ্যাটবক্স

1. **আজকের ক্লাস ও রুটিন**: লগইন করলেই শিক্ষক তার আজকের ক্লাস কোন সময়ে এবং কোন রুমে তা দেখতে পান।
2. **হাজিরা গ্রহণ**: ক্লাসে গিয়ে সংশ্লিষ্ট ব্যাচের হাজিরার অপশন ওপেন করে শিক্ষার্থীদের নাম দেখে দ্রুত Present/Absent মার্ক করে সেভ করতে পারেন।
3. **পরীক্ষার নম্বর প্রদান**: পরীক্ষার পর শিক্ষার্থীদের প্রাপ্ত নম্বর এন্ট্রি দিলে স্বয়ংক্রিয়ভাবে সর্বোচ্চ নম্বর ও মেধা তালিকা তৈরি হয়।
4. **ইন-অ্যাপ মেসেজিং**: যেকোনো প্রাতিষ্ঠানিক প্রয়োজনে অ্যাডমিনের সাথে অথবা অনুমোদিত শিক্ষার্থীদের পড়াশোনার সহযোগিতায় মেসেজ আদান-প্রদান করতে পারেন।

## 👨‍🎓 শিক্ষার্থী পোর্টাল ব্যবহারের নির্দেশিকা (Student Portal)

শিক্ষার্থী ও অভিভাবকদের জন্য ডেডিকেটেড পোর্টাল রুট: `/dashboard/student`

```

├── 🏆 পরীক্ষার ফলাফল ও মেধা স্থান (Rank)
├── 📜 প্রাতিষ্ঠানিক নোটিশ বোর্ড

2. **উপস্থিতির হিসাব**: মাসে কত দিন উপস্থিত ছিল এবং উপস্থিতির শতকরা হার কত তা রঙিন প্রগ্রেস বারে দেখা যায়।
3. **অনলাইন রেজাল্ট কার্ড**: পরীক্ষা প্রকাশিত হলে শিক্ষার্থী তার প্রাপ্ত নম্বর, পূর্ণমান, লেটার গ্রেড এবং ব্যাচে তার অবস্থান দেখতে ও ডাউনলোড করতে পারে।
4. **শিক্ষক ও অ্যাডমিনের সাহায্য**: পড়াশোনা সংক্রান্ত প্রশ্নে নিজ বিষয়ের শিক্ষকের সাথে অথবা যে কোনো অ্যাকাডেমিক সমস্যায় অ্যাডমিন হেল্পডেস্কে মেসেজ পাঠাতে পারে।

## ⚡ রিয়েল-টাইম চ্যাট ও সকেট সার্ভার (Real-Time Communication)

সিস্টেমে ব্যবহৃত হয়েছে **Socket.IO** যা কোনো পেজ রিলোড ছাড়াই তাৎক্ষণিক মেসেজ ডেলিভারি নিশ্চিত করে।

### ১. সার্ভার চালনা করার কমান্ড

রিয়েল-টাইম মেসেজিং সার্ভারটি ব্যাকএন্ডে সবসময় অ্যাক্টিভ রাখতে হবে:

```bash
# টার্মিনাল ১: Next.js ফ্রন্টএন্ড ও REST API (Port 3000)
npm run dev

# টার্মিনাল ২: পারসিস্টেন্ট সকেট সার্ভার (Port 4000)
npm run socket
```

### ২. মেসেজিং নিরাপত্তা ও চ্যাট পলিসি

- চ্যাট সংযোগে JWT টোকেন দ্বারা অথেনটিকেশন নিশ্চিত করা হয়।
- একজন ইউজার শুধুমাত্র তার অনুমোদিত কনভারসেশনে মেসেজ পাঠাতে ও গ্রহণ করতে পারেন।
- অ্যাডমিন সেটিংস থেকে শিক্ষার্থী-শিক্ষক সরাসরি চ্যাট করার অনুমতি নিয়ন্ত্রণ করতে পারেন।
- প্রতিটি বার্তার সাথে টাইমস্ট্যাম্প এবং সেন্ডারের নাম বাংলায় প্রদর্শিত হয়।
